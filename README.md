# Nested Selectors App

This is the GitHub repository for this project I made using **Angular** and **Bootstrap** as a *Nested Selectors App* example which uses the [apicountries.com](https://www.apicountries.com/) free, keyless REST Countries API to make a http request for Regions, Coutries and Border Countries for the selected Country.

## Requirements

- Node.js 24.15.0 (see `.nvmrc`)

## Development

```bash
npm install
npm start
```

## Build

```bash
npm run build:prod
```

### Now it's deployed here https://nested-selectors-tcp.netlify.app
